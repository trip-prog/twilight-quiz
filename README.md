# Сумерки — для тебя ♡

Пять отдельных викторин по пяти фильмам: по 30 вопросов, 150 всего. В каждой — 15 вопросов по памяти и 15 с началом сцены. После ответа открываются объяснение и полный отрывок. Русская озвучка сохранена.

Прогресс каждой части сохраняется в `localStorage` этого браузера. Перезагрузка возвращает к последней открытой части, включая уже выбранный ответ. Кнопка «К фильмам» позволяет переключиться между частями. Повторное прохождение сбрасывает только выбранную часть. На другом устройстве или после очистки данных браузера сохранение не переносится.

## Запуск и проверка

Обычный статический сайт, без сборки и зависимостей:

```sh
python -m http.server 4175
node check.mjs
```

Открыть `http://localhost:4175/`. Для проверки видео нужен `ffprobe` из FFmpeg. Одна проверка проверяет все данные и файлы, H.264/AAC, длительности, faststart, завершение пяти игр, подсчёт баллов, восстановление сохранений и защиту от повторного ответа.

GitHub Pages публикует корень ветки `main`. `.nojekyll` исключает обработку Jekyll. Все адреса файлов относительные; интернет требуется для загрузки сайта и роликов.

## Вопросы и видео

`questions.json` содержит текст, четыре варианта, индекс правильного ответа, объяснение, пути видео и сведения об источнике. `film` — номер фильма от 1 до 5. `source.start/end` — секунды в исходной подборке, `introStart/introEnd` — отдельный вступительный файл, `revealStart` — граница раскрытия ответа. Начала для вопросов с продолжением физически отделены от развязок.

Источник: [пять фильмов с русским дубляжом](https://vk.com/video-241348730_456239029). Начало частей в подборке: 0, 6967, 14283, 21208 и 27577 секунд. Все вопросы сопоставлены с диалогом или действием в соответствующем отрывке. Из вариантов исключены сцены с посторонними рекламными плашками.

`tools/prepare_media.py` воспроизводит нарезку из метаданных источника и локального аудио в `.work/`; при наличии подготовленных отрывков использует их. `.work/` не публикуется. Ролики имеют разрешение до 720p, H.264/AAC и faststart; основная подборка сжата до 540p для загрузки на телефонах. Права на фильмы и их звук принадлежат правообладателям.
