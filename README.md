# Сумерки — для тебя ♡

Пять фильмов, по 100 вопросов на каждый, 500 всего. Переключатель на главной выбирает основную игру (30 вопросов) или дополнение (70 новых). В основной игре по-прежнему 15 вопросов по памяти и 15 с началом сцены; дополнение — вопросы по памяти о репликах, поступках и деталях. После каждого ответа открываются объяснение и короткий отрывок с русской озвучкой.

В основной игре ролики с ответами обычно длятся 8–15 секунд (медиана — 10 секунд), вступления — около 6 секунд. Начало и развязка нарезаны независимо, без длинного повторения вступления. В дополнении 350 отрывков длительностью 5–12 секунд, медиана — 5,6 секунды. Все медиа сайта занимают около 343 МиБ.

Пять персональных портретов с разными вампирскими образами находятся в `media/portraits/`. Фотография каждой части показана на выборе фильма, фоном игры и на экране результата. В «Затмении» использовано новое фото с букетом вместо повторявшегося снимка. На широком экране фон расположен сбоку от игры, на телефоне — в верхней части страницы. Кнопка следующего вопроса прокручивает страницу к игре; существующие сохранения продолжают работать.

Прогресс каждой части и каждого набора сохраняется отдельно в `localStorage` этого браузера. Старые сохранения основной игры совместимы: её вопросы, порядок и идентификаторы не изменены. Перезагрузка возвращает к последнему набору и фильму, включая уже выбранный ответ. Кнопка «К фильмам» позволяет переключаться. Повторное прохождение сбрасывает только выбранный набор выбранной части. На другом устройстве или после очистки данных браузера сохранение не переносится.

## Запуск и проверка

Обычный статический сайт, без сборки и зависимостей:

```sh
python -m http.server 4175
node check.mjs
```

Открыть `http://localhost:4175/`. Для проверки видео нужен `ffprobe` из FFmpeg. Одна проверка проверяет все данные и файлы, H.264/AAC, длительности, faststart, прохождение обоих наборов каждого фильма, подсчёт баллов, восстановление сохранений и защиту от повторного ответа.

GitHub Pages публикует корень ветки `main`. `.nojekyll` исключает обработку Jekyll. Все адреса файлов относительные; интернет требуется для загрузки сайта и роликов.

## Вопросы и видео

`questions.json` содержит основную игру, `extra-questions.json` — дополнение. Каждая запись содержит текст, четыре варианта, индекс правильного ответа, объяснение, подтверждающую реплику, пути видео и сведения об источнике. `film` — номер фильма от 1 до 5. `source.start/end` — секунды в исходной подборке, `introStart/introEnd` — отдельный вступительный файл, `revealStart` — граница раскрытия ответа. Начала для вопросов с продолжением физически отделены от развязок.

Источник: [пять фильмов с русским дубляжом](https://vk.com/video-241348730_456239029). Начало частей в подборке: 0, 6967, 14283, 21208 и 27577 секунд. Все вопросы сопоставлены с диалогом или действием в соответствующем отрывке. Из вариантов исключены сцены с посторонними рекламными плашками.

`tools/prepare_media.py` воспроизводит нарезку из метаданных источника и локального аудио в `.work/`; при наличии подготовленных отрывков использует их. Для дополнения: `python tools/prepare_media.py --extra`; `--force` пересоздаёт уже существующие ролики. `.work/` не публикуется. Ролики сжаты до 540p, имеют H.264/AAC и faststart для загрузки на телефонах. Права на фильмы и их звук принадлежат правообладателям.
